# simpleBudget Landing Site

Static marketing site built with [Astro](https://astro.build).

## Pages

- `/` — Landing page
- `/pricing` — Pricing & FAQ
- `/about` — About page
- `/privacy` — Privacy policy
- `/terms` — Terms of service

## Development

```bash
cd marketing
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build    # outputs to dist/
npm run preview  # preview the build locally
```
