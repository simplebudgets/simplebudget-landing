Every simpleSuite app (simpleBudget, simpleTracker, etc.) is a Progressive Web App (PWA) that you can install directly from Chrome — no Play Store needed.

## Steps

1. **Open Chrome** and go to the app you want to install:
   - simpleBudget: [budget.simplesuite.dev](https://budget.simplesuite.dev)
   - simpleTracker: [tracker.simplesuite.dev](https://tracker.simplesuite.dev)
2. You should see a banner at the bottom saying **"Add to Home screen"** — tap it
3. If no banner appears, tap the **three-dot menu** (⋮) in the top-right corner
4. Tap **"Install app"** or **"Add to Home screen"**
5. Confirm by tapping **Install**

The app icon will appear on your home screen and in your app drawer.

## Tips

- Works in **Chrome, Edge, and Samsung Internet** — most Chromium-based browsers support PWA install
- The app opens in its own window with no browser UI
- It works offline — data syncs automatically when connectivity returns
- Updates happen in the background — you'll see a prompt when a new version is ready
- You can install multiple simpleSuite apps — each gets its own icon

## Troubleshooting

**No install banner or option?**
- Make sure you're signed in (the install prompt typically appears on the authenticated app)
- Try clearing your browser cache and reloading
- Some browsers require you to visit the site a couple of times before offering the install prompt

**App feels stuck on an old version?**
Tap "Update" when prompted, or uninstall and reinstall from the browser to force a fresh cache.
